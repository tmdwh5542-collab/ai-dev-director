# 회사 PC를 집 태블릿·휴대폰에서 사용하기

PC가 실행 서버입니다. 태블릿·휴대폰에서는 브라우저 또는 홈 화면 아이콘으로 같은 회사 화면에 접속합니다. AI 호출·개발 파일·Unity/Godot·테스트·회의 기록은 PC에 있습니다. 모바일 화면을 닫거나 네트워크가 잠시 끊겨도 이미 접수된 미션은 PC에서 계속 진행됩니다.

태블릿에서 Windows EXE나 게임 엔진을 독립 실행하는 기능은 아닙니다. PC를 끄거나 절전시키면 접속과 작업을 진행할 수 없습니다. PC 앱의 창만 닫으면 기존처럼 서버는 유지되지만, **시스템 중지**는 서버와 기기 접속을 종료합니다.

## 사용 가능한 범위

| 기능 | PC | 등록한 태블릿·휴대폰 |
| --- | --- | --- |
| 회사·캐릭터·직원·부서 확인과 편집 | 가능 | 가능 |
| 미션 준비·실행·중단·결과 확인 | 가능 | 가능 |
| 부서/임원 회의·보고서·안건 승인 | 가능 | 가능 |
| 총괄 AI와 대화, 기존 실행의 승인/반려 | 가능 | 가능 |
| PC에 등록된 프로젝트 선택 | 가능 | 가능 |
| 새 PC 폴더 선택·엔진 실행 경로 설정 | 가능 | PC에서 설정 |
| PC 시스템 중지·기기 연결 관리·AI 연결 변경 | 가능 | PC에서 설정 |

회사·팀·미션·보고함·현재 프로젝트 선택은 PC와 공유됩니다. 미션 요청에는 선택한 프로젝트를 캡처하고 요청 ID를 보존해 재접속/재전송 중 중복 실행을 방지합니다. 작성 중인 초안은 각 브라우저에 보관하므로 다른 기기로 자동 이전되지 않습니다. 모바일에서는 PC에 등록/선택한 프로젝트만 새 실행 대상으로 쓸 수 있습니다.

## 1. 개선판 설치

기존 프로그램에서 **시스템 중지 → 창 닫기**, 새 ZIP을 모두 풀고 `INSTALL_DESKTOP.cmd`를 실행합니다. 새 버전은 HTTPS와 QR 생성 패키지도 설치합니다. 기존 회사·직원·프로젝트·회의 데이터는 보존합니다.

회사 사무실이나 미션 센터의 **기기 연결**, 또는 전용 앱의 **앱 → 태블릿·휴대폰 연결**을 엽니다. 기기 연결은 처음에는 꺼져 있습니다.

## 2. 회사와 집처럼 다른 네트워크에서 연결

1. 회사 PC와 집의 태블릿·휴대폰에 [Tailscale](https://tailscale.com/download)을 설치합니다.
2. 두 기기를 같은 계정/사설 네트워크에 연결합니다. 태블릿·휴대폰에서 OS가 요청하는 VPN 연결도 허용합니다.
3. PC 프로그램의 **기기 연결 → 주소 새로고침**을 누릅니다.
4. **외부 연결 · Tailscale / 100.x.x.x** 주소를 선택하고 **기기 연결 켜기**를 누릅니다.
5. 화면에 표시된 주소/QR로 연결합니다. 집 Wi-Fi, 다른 Wi-Fi, LTE·5G에서도 해당 기기의 Tailscale이 연결되어 있으면 같은 주소를 사용합니다.

공유기의 포트를 열거나 공인 IP를 입력할 필요가 없습니다. Tailscale은 별도 프로그램이며, 설치·로그인·회사 네트워크의 연결 허용은 실제 기기에서 해야 합니다. 이 배포 파일이 Tailscale 계정이나 VPN을 자동 생성하지는 않습니다. 회사 네트워크에서 VPN/통신을 제한하면 해당 네트워크의 연결 설정을 확인해야 합니다.

처음 기기 등록은 PC 화면의 코드를 볼 수 있을 때 하세요. 태블릿을 미리 등록해 두고 집에서 이어서 쓰는 방법이 편합니다. 처음부터 집에서 등록한다면 PC의 코드를 3분 안에 확인할 수 있어야 합니다.

## 3. 같은 Wi-Fi에서만 연결

PC와 기기를 같은 Wi-Fi/LAN에 연결합니다. PC 화면에서 **같은 네트워크 · Wi-Fi/LAN / 192.168.x.x, 10.x.x.x 등**을 선택하고 연결을 켭니다. 이 주소는 다른 집/회사 네트워크에서 직접 접근할 수 없습니다.

Tailscale 주소를 선택하면 같은 Wi-Fi에서도 Tailscale이 연결된 기기로 접속할 수 있습니다. 한 번에 한 주소로 연결하므로, 같은 Wi-Fi와 외부 모두 사용할 목적이면 Tailscale 주소를 권장합니다.

기본 기기 연결 포트는 **8443**, 기존 PC 실행 서버는 **8081**입니다. 포트가 사용 중이면 기기 연결 화면에서 다른 1024~65535 포트를 선택할 수 있습니다. PC 실행 서버는 계속 127.0.0.1에만 연결되며 공개하지 않습니다.

## 4. QR·연결 코드로 기기 등록

1. 태블릿·휴대폰 카메라로 QR을 읽거나 표시된 `https://.../pair` 주소를 브라우저에 입력합니다.
2. 첫 접속에서는 PC가 자체 발급한 로컬 HTTPS 인증서 안내가 나올 수 있습니다. PC에 표시된 주소인지 확인하고 브라우저에서 해당 연결을 허용합니다. 필요하면 PC의 **인증서 SHA-256**과 브라우저 인증서를 비교할 수 있습니다. QR에는 주소만 들어갑니다.
3. PC에서 **1회용 연결 코드 발급**을 누릅니다.
4. 모바일에 기기 이름과 **8자리 코드**를 입력합니다. 코드는 **3분 / 기기 1대**에만 사용됩니다.
5. 회사 화면이 열리면 등록 완료입니다. 브라우저 메뉴의 **홈 화면에 추가**로 아이콘을 만들어 사용할 수 있습니다. iOS 등에서는 홈 화면 앱의 저장 공간이 별도여서 첫 실행에 기기를 다시 등록해야 할 수 있습니다.

등록은 최대 **30일**, 동시에 최대 **10대**입니다. 모바일의 개인 정보 보호/데이터 삭제 설정에 따라 브라우저가 더 일찍 연결 정보를 지울 수 있습니다. 코드가 재사용되거나 만료되면 PC에서 새 코드를 발급하세요.

연결된 모바일 화면 위에는 **PC 연결** 배너, **상태 새로고침**, **기기 연결 해제** 버튼이 표시됩니다. PC가 응답하지 않으면 연결 확인 상태로 표시하고 성공을 꾸며내지 않습니다. 통신이 끊긴 실행 요청은 같은 요청 ID의 접수 상태부터 확인하세요.

## 5. 등록 해제와 PC 재시작

- PC의 등록 기기 목록에서 **기기 해제**: 해당 기기만 다음 요청부터 차단합니다. 다른 기기는 유지됩니다.
- 모바일 배너의 **기기 연결 해제**: 이 기기를 등록 해제합니다.
- PC의 **연결 끄기 · 등록 해제**: HTTPS 접속을 끄고 등록된 모든 기기를 해제합니다. 이미 PC에서 진행 중인 개발 작업은 계속됩니다.
- 켜진 연결은 PC 서버를 재시작하면 같은 주소와 포트로 복구를 시도합니다. 등록/인증서도 만료 전까지 유지합니다. 주소가 바뀌거나 포트를 사용할 수 없으면 PC 실행은 유지하고 연결 설정에서 오류를 안내합니다.

기기 관리와 시스템 종료는 PC에서만 할 수 있습니다. 공유하는 회사 설정은 기존 충돌 검사를 사용하므로 다른 기기가 먼저 저장한 내용을 조용히 덮어쓰지 않습니다.

## 연결이 안 될 때

- 회사 PC가 켜져 있고 프로그램의 서버가 실행 중인지, 절전 중이 아닌지 확인합니다.
- 외부 접속은 PC와 모바일 양쪽의 Tailscale 연결과 같은 사설 네트워크 계정을 확인합니다.
- 생성된 주소의 HTTPS, IP, 포트가 정확한지 확인합니다. 원격 주소는 `localhost`가 아닙니다.
- Windows 방화벽 알림이 나타나면 선택한 사설 네트워크에서 프로그램의 연결을 허용해야 합니다. 회사 관리 기기라면 필요한 연결 허용을 담당자에게 확인합니다.
- 게스트 Wi-Fi의 기기 간 차단, VPN 차단, 회사의 네트워크 제한이 있으면 연결할 수 없습니다.
- 브라우저에 인증서 안내가 나오면 PC에 표시된 주소와 인증서를 확인합니다. 서버는 HTTP로 자동 전환하지 않습니다.
- 연결 정보가 만료/해제되었으면 코드로 다시 등록합니다. 태블릿에서 Windows 설치 파일을 실행하지 않습니다.

## 저장과 검증

설정: `data/device_link.json`, 등록 기기의 해시된 인증 정보: `data/paired_devices.json`, 로컬 인증서: `data/device-link/`. 모두 PC의 사용자 데이터 폴더에 저장하고 재설치 시 보존합니다. 키와 등록 토큰은 소스 ZIP에 포함하지 않습니다. 모바일에 PC 내부의 bridge 토큰을 전달하지 않으며, 경로 허용 목록·기기별 요청 인증·출처 검사·만료/해제·요청 크기/연결 수/코드 시도 제한을 적용합니다.

자동 검사에서는 실제 HTTPS 서버와 서로 다른 PC·휴대폰·태블릿 브라우저 세션을 사용했습니다. 코드 1회 사용, QR, 인증 쿠키, 동기화, 모바일 실행 접수, PC 전용 기능 차단, 연결 끊김/복구와 해제를 확인했습니다. 실제 회사↔집 라우터, Tailscale 로그인/정책, Windows 방화벽, iPad/Android 실물 기기의 홈 화면 동작은 이 Linux 환경에서 확인하지 못했습니다.
