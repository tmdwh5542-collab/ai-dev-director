# Hermes Agent 비서 보조 연동

Hermes Agent가 설치된 별도 Python 환경에서 SDK를 실행하는 선택 기능입니다. 기본값은 비활성이며, Hermes 자체·개인 프로필·플러그인·API 키를 이 앱에 자동 설치하거나 가져오지 않습니다. 사용자가 요청할 때까지 새 설치 ZIP을 만들지 않고 소스 패치를 누적합니다.

## 제공 기능

- 담당 직원을 선택해 제공 자료와 같은 프로젝트의 최근 미션 기록을 분석하도록 요청합니다.
- 공개 GitHub Markdown 파일 주소를 지정하면 앱이 문서를 읽어 참고 자료로 전달합니다. 검색 엔진이나 저장소 코드 설치는 실행하지 않습니다.
- 결과는 요약·추천 조치·확인할 질문을 담은 보고서로 제출합니다.
- 대표가 채택한 추천 조치만 같은 프로젝트의 다음 계획·총괄 대화에 참고 지침으로 전달합니다. 채택은 코드 변경·패키지 설치·결제·배포를 즉시 실행하지 않습니다.
- 기존 HEAD/BUILDER/REVIEWER의 개발·검증·검수 흐름은 유지합니다. Hermes는 해당 역할을 자동 대체하지 않습니다.
- 실제 호출을 기존 작업 장부에 `runtime=hermes-sdk`, 담당 직원, 실제 모델 제공자와 함께 기록합니다. 완료 보고서에는 실행 환경·버전·시간·API 사용 여부와 SDK가 보고한 사용량을 남깁니다.
- 작업별 중지와 전체 작업 중지에 연결됩니다. 재시작 후 중단된 업무를 자동 재호출하지 않습니다.

## 초기 설정

1. 실행할 PC·맥미니에 [Hermes 공식 설치 안내](https://github.com/NousResearch/hermes-agent)를 따라 별도 환경을 준비합니다.
2. 앱의 **AI·스킬 설정 → Hermes Agent 실행 연동**에서 Hermes 환경의 Python 실행 파일 절대 경로를 입력합니다. 예: `…/hermes-agent/.venv/bin/python`, Windows는 `…\.venv\Scripts\python.exe`.
3. 설치 환경이 소스 체크아웃을 사용하는 경우 `run_agent.py`가 있는 폴더를 지정합니다. 일반적인 `.venv` 배치는 자동 감지하며 설치된 패키지를 가져올 수 있으면 폴더를 비워도 됩니다.
4. OpenAI API / Claude API / Gemini API와 사용할 모델 ID를 선택합니다. 정확한 모델 ID는 이용 중인 제공자에서 확인합니다.
5. 키를 PC의 환경변수에 등록한 뒤 앱을 다시 실행합니다. 기본 변수는 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `GEMINI_API_KEY`입니다. 앱에는 변수 이름만 저장하며, 키 본문을 이 대화나 업무 자료에 붙여 넣지 마세요.
6. 설정 저장 후 **저장된 실행 환경 점검**을 누릅니다. 설치 점검은 패키지·SDK 인터페이스를 확인할 뿐 계정 인증·모델 이용 권한·요금 한도를 검증하지 않습니다.
7. 회사 사무실의 **Hermes 자료 분석·보고**에서 프로젝트와 담당 직원을 선택하고 요청합니다.

Hermes 원본이 요구하는 Python 버전·의존성은 Hermes 공식 설치 환경에서 관리합니다. 앱의 Python이나 기존 CLI 설치를 교체하지 않습니다. 이 어댑터는 공식 `AIAgent`의 명시적 도구 제한·capabilities 기능을 요구하고, 해당 기능이 없는 버전은 실행을 거부합니다.

## 비용과 한도

Hermes 소프트웨어는 MIT 오픈소스입니다. 이 어댑터는 **모델 API 연결**을 사용합니다. 기존 Codex·Claude Code CLI 구독 로그인은 이 어댑터에서 재사용하지 않으며, 모델 API의 별도 비용·할당량이 적용됩니다.

기본값은 하루 업무 요청 5건, 동시 업무 1건, 업무당 180초입니다. 설정에서 하루 1~30건, 30~600초로 변경할 수 있습니다. 하루 기준은 한국 시간이며 접수된 실패 요청도 요청 한도에 포함합니다. 같은 요청 ID를 재전송하면 기존 접수 기록을 반환해 중복 실행을 막습니다.

자동 작업 재시도와 다른 제공자로의 자동 전환을 하지 않습니다. SDK의 모델 실행은 최대 1회 반복과 출력 제한을 적용하지만 SDK·HTTP 계층의 재시도/사용량은 제공자 정책에도 영향을 받습니다. **요청 건수·시간·출력 제한은 금액 한도가 아닙니다.** 실제 비용은 제공자 청구 내역을 기준으로 확인하세요. 기존 작업 장부의 토큰 수는 추정값이며 SDK가 반환한 사용량은 보고서에 별도로 표시합니다.

## 실행 범위

첫 연동 범위는 **제공 자료 분석과 보고서 작성**입니다. Hermes의 전체 기능이 활성화된 상태가 아닙니다.

- 도구 목록을 명시적으로 비우고, 호스트 기능을 비활성화합니다. 셸·파일 편집·웹 검색·브라우저·외부 MCP·플러그인 실행·장기 기억·스킬 자동 학습은 활성화하지 않습니다.
- 작업별 임시 프로필·작업 폴더와 별도 프로세스를 사용합니다. 개인 Hermes 설정·기억·인증 파일을 복사하지 않습니다. 앱에서 검토·활성화한 스킬은 참고 지침 텍스트로만 제공합니다.
- 선택한 API 키는 자식 프로세스 환경으로만 전달하며 명령행·앱 설정·업무 보고서에 저장하지 않습니다.
- 공식 CLI의 공유 게이트웨이를 호출하는 대신 SDK 프로세스를 직접 관리해 중지·시간 초과 시 해당 프로세스를 종료합니다. 부모 앱이 종료되면 작업 프로세스도 종료하도록 감시합니다. 외부 API에 이미 접수된 요청의 청구 취소를 보장하는 기능은 아닙니다.
- 앱 차원의 기능 제한이며 운영체제 컨테이너 격리를 제공한다고 주장하지 않습니다.

태블릿·휴대폰의 등록된 HTTPS 연결에서는 업무 요청·보고서 확인·채택·중지를 사용할 수 있습니다. 실행 환경 등록·설치 점검·키 설정 경로는 PC 전용입니다. 원격 업무는 PC에서 등록한 프로젝트에만 요청할 수 있습니다.

## 검증과 한계

격리 테스트에서 실제 앱의 설정·업무 접수·중복 방지·한도·장부·중지·오류·대표 채택·같은 프로젝트 지침 전달·HTTP 인증 경계를 검증합니다. 별도 Python 프로세스에 SDK 계약을 구현한 시험 모듈을 넣어 도구 제한·직접 실행·JSON 프로토콜을 검사합니다. 브라우저 검수는 명시적인 시험용 SDK 응답을 사용합니다.

현재 작업 환경에 Hermes 원본 패키지를 설치하거나 실제 사용자 계정/유료 모델을 호출하지 않았습니다. 따라서 실제 Hermes 배포 버전·모델·인증·Windows/macOS 실물 환경의 종단 실행은 사용자 환경을 등록한 뒤 확인해야 합니다. 설치 점검 통과를 실제 추론 성공으로 표시하지 않습니다.
