# Windows 전용 데스크톱 앱

Windows 설치용 ZIP을 모두 압축 해제한 뒤 `INSTALL_DESKTOP.cmd`를 실행합니다.
첫 설치에는 **Windows 10/11 64비트, Python 3.10 이상 64비트, Git, 인터넷 연결**이 필요합니다.
패키지 설치와 EXE 생성이 끝나면 바탕화면의 **AI DEV DIRECTOR v3** 아이콘으로 실행합니다.
실제 개발 작업에는 로그인한 AI 코딩 CLI가 필요합니다.

## 전용 창과 실행 파일

`native_app.py`는 PySide6의 QMainWindow와 QtWebEngine을 사용하는 데스크톱 앱입니다.
기존 미션 센터 화면을 내부 화면 엔진에서 표시하며 자체 아이콘·제목·앱 메뉴를 제공합니다.
앱 메뉴에서 새로고침, 확대/축소, 기록 폴더 열기를 사용할 수 있습니다.
보고서 다운로드는 앱의 파일 저장 대화상자로 처리합니다.
외부 HTTPS 링크를 직접 누르면 기본 브라우저에서 열며, 앱의 주 화면은 해당 설치의 로컬 주소로 제한합니다.

설치 중 `scripts/build_native_app.py`가 PyInstaller로 GUI EXE와 Qt 런타임 폴더를 만듭니다.
바로가기 대상은 `native\AI-DEV-DIRECTOR\AI-DEV-DIRECTOR.exe --app-root <설치 폴더>`입니다.
EXE 옆의 `_internal` 등 생성 파일도 실행에 필요하므로 EXE만 옮기지 마세요.
백엔드는 설치 폴더의 `.venv` Python으로 실행합니다. 검증 작업이 Python을 직접 호출할 수 있도록 별도로 유지합니다.
ZIP에는 미리 생성된 Windows EXE가 없으며 Python 없이 설치되는 단일 EXE 배포판은 아닙니다.

## 설치 위치와 데이터

- 프로그램: `%LOCALAPPDATA%\AI Dev Director\mission-center-v3`.
- 바로가기: Windows가 알려주는 DesktopDirectory 경로. OneDrive와 한글 경로를 따릅니다.
- 화면 저장소: 설치 폴더 `data/webview`. 사용자의 일반 브라우저 프로필과 별도입니다.
- 새 설치 포트: 8091 우선, 사용 중이면 빈 포트를 저장합니다.
- 기존 trial과 원래 바로가기는 보관합니다. 기존 자료를 자동으로 가져오지는 않습니다.
- 설치 후 다운로드/압축 해제 폴더를 이동해도 바로가기는 유지됩니다.

관리자 권한, 전역 Python 패키지 설치, PowerShell 실행 정책 변경은 사용하지 않습니다.
설치 파일의 SHA-256 목록은 추출 오류를 확인하는 용도이며 배포자 서명은 아닙니다.

## 실행과 종료

설치별 파일 잠금과 `/ops/desktop-health`의 설치 경로 해시로 서버 중복 시작과 다른 설치본 연결을 막습니다.
시작 실패 시 직접 생성한 서버 자식만 정리합니다. 다른 포트 점유 프로그램은 중지하지 않습니다.
앱 창을 닫아도 서버와 진행 중인 작업은 유지됩니다. **시스템 중지**로 서버를 종료합니다.
서버 시작 중 창을 닫으면 창은 숨기고 시작 처리가 끝난 뒤 GUI를 정리합니다.
기존 설정에 따라 중단된 미션이 시작 시 재개될 수 있습니다.

재설치는 서버를 시스템 중지하고 전용 앱 창을 닫은 뒤 새 ZIP에서 실행하세요.
기존 `config.yaml`, `companion.json`, 데이터·실행 기록·가상환경은 보관합니다.
오류 기록은 `data/desktop-launcher.log`, 서버 출력은 `data/desktop-server.log`, `data/desktop-server.err`입니다.

## 검증 범위

런처/설치/전용 앱 관련 자동 테스트 **19개 통과**:
설치 구분, 동시 시작, 실제 자식 서버 시작/재사용, 설정 보존, 배포 해시/경로 검사,
전용 EXE 바로가기 인자와 한글·공백 경로 전달, 내부/외부 탐색 제한을 확인했습니다.
Linux의 실제 QtWebEngine 창으로 임시 미션 서버에 연결해 13개 미션 데이터와 보고서 저장도 검증했습니다.
테스트는 실제 AI CLI를 호출하지 않습니다.

현재 환경은 Linux이므로 Windows EXE 생성, 작업표시줄 표시, COM 바로가기의 실제 실행은 검증하지 못했습니다.
헤드리스 테스트의 화면 렌더링 스크린샷은 확인 자료로 사용하지 않습니다.
컨테이너 테스트의 샌드박스 해제 환경변수는 테스트 명령에만 적용하고 제품 코드에는 넣지 않았습니다.

## 내부 화면 깜박임 수정판 (fix1)

- 작업실의 미션/진행 표시/작업량/기록은 상태 조회 때 기존 DOM 요소를 유지하며 변경된 내용만 갱신합니다.
  펼친 상세 내용, 입력 초점과 진행 표시 애니메이션을 보존합니다.
- 작업실 프레임을 다시 열 때 활동 조회 타이머가 중복 등록되던 문제를 수정했습니다.
- 화면 이동 실패/취소 신호가 와도 이미 표시된 화면을 로딩 패널로 바꾸지 않습니다.
- 전용 앱은 기본적으로 소프트웨어 그래픽과 2D 무대 표시를 사용합니다.
  고급 사용자는 EXE 실행 인자 `--hardware-graphics`로 하드웨어 그래픽을 선택할 수 있습니다.
  브라우저 보안/샌드박스 설정은 변경하지 않습니다.
- 폴더 선택 도구의 기존 Python 문법 오류를 수정했습니다.
- 화면 엔진 오류와 Qt 메시지는 `data/desktop-native.log`에 기록합니다(최대 2MB, 백업 2개).
  프로세스 자체의 치명적 오류 기록은 `data/desktop-fault.log`에서 확인합니다.
- 앱 메뉴의 새로고침으로 화면을 다시 연결할 수 있습니다. 자동 반복 재시작은 하지 않습니다.

브라우저와 실제 QtWebEngine에서 작업실 연결, 새 대화, 프로젝트 선택 동작을 확인했습니다.
브라우저에서는 후속 상태 조회 뒤에도 프레임 문서가 유지되며, 상세 내용과 초점·진행 표시 DOM이 보존됨을 확인했습니다.
Windows 사용자 PC의 그래픽 드라이버/화면 깜박임 현상 자체는 여기서 재현하지 못했습니다.
수정 후에도 반복된다면 앱 메뉴의 기록 폴더에서 `desktop-native.log` 마지막 부분으로 원인을 더 좁힐 수 있습니다.

## 게임 엔진 대응 재검수판

최신 검수 범위와 수정 사항은 [재검수 기록](REVIEW_ENGINE_EDITION_KO.md)에 정리했습니다.
새 **앱 → 게임 프로젝트 검증 설정…** 메뉴의 사용법은 [게임 제작 안내](GAME_DEVELOPMENT_KO.md)를 참고하세요.
게임 엔진 설정은 `data/engine-projects.json`에 보관되어 재설치 시 유지됩니다.


## 직원 편집 게임 개발팀 추가판

회사 사무실의 **직원·역할 편집**에서 기본 6명의 게임 개발팀을 수정할 수 있습니다.
팀 설정은 `data/team_settings.json`, 미션별 팀은 미션 기록에 저장됩니다. 재설치에서 보존합니다.
[직원 편집 안내](STAFF_TEAM_KO.md)를 참고하세요.


캐릭터 회사판은 첫 실행 시 대표 생성과 배경 선택을 안내합니다. 이전에 저장한 직원과 프로젝트는 유지됩니다. 부서·회의·비서 보고함 사용법은 [회사 운영 안내](COMPANY_SIMULATION_KO.md)를 참고하세요.


태블릿·휴대폰 연동판은 **앱 → 태블릿·휴대폰 연결**에서 HTTPS 연결을 켭니다. 기존 PC 실행 포트를 공개하지 않습니다. 회사↔집 접속에는 양쪽 기기의 Tailscale 연결이 필요합니다. [연결 안내](DEVICE_LINK_KO.md).


픽셀 스튜디오판의 캐릭터 원화는 설치 파일에 포함됩니다. 대표/직원 외형은 저장된 성별·스타일에 연결되며 기존 데이터를 보존합니다. 업데이트 후 태블릿·휴대폰의 열린 화면도 한 번 새로고침하세요. [픽셀 UI 안내](PIXEL_STUDIO_KO.md).
