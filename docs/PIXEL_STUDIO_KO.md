# 픽셀 스튜디오 · 2D 캐릭터 UI

회사 사무실과 대표/직원 생성 화면을 게임의 로비·채용 메뉴처럼 바꿨습니다. 따뜻한 종이색, 각진 프레임, 도트 스프라이트, 큰 2D 캐릭터 초상화를 함께 사용합니다. 미션 센터·보고함·기기 연결·총괄 작업실도 같은 색과 메뉴 표현을 사용합니다. 상세 모니터는 기존 실행 상황을 확인하는 별도 화면입니다.

## 두 가지 캐릭터 표현

- 사무실 안에서는 **픽셀 캐릭터**가 이동하고 실제 작업 상태에 맞춰 책상/회의 위치로 움직입니다.
- 직원을 고르면 **2D 초상화**와 이름·프로필·담당 업무를 표시합니다.
- 대표 생성에서는 성별과 다섯 스타일을 고릅니다. 초상화 선택 카드 또는 스타일 선택란을 사용할 수 있습니다.
- 직원 채용에서도 성별·이름·나이·캐릭터 스타일을 바꿀 수 있습니다. 이름/나이는 프로필이며 원화의 인상·연령을 입력 숫자대로 다시 생성하지 않습니다.
- 남성 5종·여성 5종의 원화를 제공합니다. **시티 러너 / 나이트 코더 / 실버 노트 / 레드 라인 / 골든 아워**는 각각 민트 / 블루 / 바이올렛 / 코랄 / 골드에 연결됩니다.
- 이미 만든 대표/직원은 저장한 성별·색상에 맞춰 새 원화와 픽셀 모습을 사용합니다. 별도 데이터 초기화나 직원 재생성이 필요하지 않습니다. 예전 기록에 외형이 없으면 기본 모습을 표시하며 채용·편집에서 변경할 수 있습니다.

## 사무실과 기존 기능

대기업 본사·자유로운 스튜디오·그린 오피스의 선택과 대표 이동, 부서 전환, 직접 채용, 부서별 정원, 회의·승인, PC↔태블릿·휴대폰 연결은 이어서 사용할 수 있습니다. 캐릭터 그림체가 AI 계정·능력·실행 권한을 바꾸지는 않습니다.

서버 상태를 갱신할 때 초상화 노드를 매번 다시 만들지 않습니다. 원화 파일은 기기에 캐시하고, 프로그램과 실제 프로젝트/대화 데이터는 기존처럼 별도로 갱신합니다. 원화 로딩이 실패하면 내장 벡터 그림을 표시해 화면과 조작이 유지됩니다. 원격 접속은 등록된 기기에서만 원화 파일에 접근할 수 있고, 인증 실패 응답은 캐시하지 않습니다.

## 아트 구성

- `assets/crew-portraits.png`: 이 작업에서 이미지 생성 도구로 제작한 오리지널 캐릭터 원화 10종의 아틀라스.
- `console/character-art.js`: 같은 팔레트의 픽셀 스프라이트와 초상화 표시, 내장 대체 그림.
- `console/pixel-theme.css`: 사무실·생성·채용·미션·회의·기기 연결·작업실의 시각 표현.

원화는 프로그램에 포함되어 있어서 실행할 때마다 AI로 그림을 생성하거나 별도 이미지 서비스를 호출하지 않습니다. 초기 로딩 후 기기 내 캐시를 사용합니다. 배포본에는 원본 이미지와 해시가 포함됩니다.

## 업데이트

기존 앱에서 **시스템 중지 → 창 닫기**, 새 ZIP을 풀고 `INSTALL_DESKTOP.cmd`를 실행합니다. 기존 데이터 폴더를 보존하므로 회사·직원·프로젝트·회의·기기 등록을 이어서 사용합니다. 이 ZIP은 Windows 설치판입니다. macOS 설치판이나 Android APK/iOS 설치 파일을 추가한 배포는 아닙니다.

## 검증 범위

PC·모바일·태블릿 브라우저에서 대표 생성, 남녀/스타일 선택, 직원 편집과 저장, 부서 전환, 실제 이동, 초상화 노드 유지, 보고함·일괄 승인, 원격 HTTPS의 원화 표시와 기기 해제를 확인합니다. 미션 센터·실행 센터의 요청·보고서와 실제 QtWebEngine도 검사합니다. AI 응답은 격리된 테스트 대역을 사용하며 Windows·실물 모바일 기기의 최종 표시는 해당 기기에서 확인해야 합니다.

## 직사각형 사무실·AI 연결 설정 패치

대표실/비서실과 일곱 부서의 사무실을 별도 직사각형 맵으로 분리했습니다. 이전/다음 화살표와 부서 버튼으로 이동하며, 방 선택은 기기별로 기억합니다. 현재 방의 직원만 렌더링합니다. 회사·팀 정보는 revision이 바뀔 때만 재전송하고 작업 요약은 한 요청으로 묶었습니다. 기본 갱신은 대기 중 약 8초, 작업/보고 이동 중 약 3초이며 숨겨진 탭에서는 멈춥니다.

대표는 현재 방문 중인 방에 표시됩니다. 부서 직원은 소속 방에, 사용자가 채용한 비서는 대표실 앞 비서실 자리에 배치됩니다. 비서를 임의로 생성하지 않습니다. 실제 구현·검수 호출에 맞춘 협업 방문, 회의 참석, 미션·부서회의 완료 후 관련 과장→비서→대표의 보고 전달을 움직임으로 보여줍니다. 이동은 실제 파일 처리의 물리적 위치나 여러 AI의 동시 실행을 뜻하지 않습니다. 보고 이동은 완료 직후 약 70초간 표시하고 원본은 미션 기록·회의 보고함에 남깁니다. 비서 미채용 시 대표 보고함 전달로 표시합니다.

배경 선택 시 **현재 사무실만 / 전체 사무실**을 선택할 수 있습니다. 전체 변경은 개별 방의 이전 배경 설정을 초기화합니다. 하반신의 네모 오류는 구형 캐릭터 CSS가 픽셀 다리의 채움·선을 덮어쓴 것이 원인이어서 적용 범위를 수정했습니다.

대표 주재 임원회의는 등록된 프로젝트의 실제 배정·미션·검증 기록을 정리하여 과장들이 순서대로 보고합니다. AI가 추측한 완료율이나 가상의 작업을 넣지 않습니다. 대표가 승인하거나 추천 답변/직접 답변을 전달하면 다음 과장이 보고합니다. 새로고침·재시작 후에도 발표 순서와 답변을 보존하고, 같은 프로젝트의 다음 계획에 대표 지침으로 전달합니다. 이 승인은 외부 설치·결제·배포 권한을 추가하지 않습니다.

상단 **AI·스킬 설정**은 PC 전용입니다. 휴대폰/태블릿의 원격 게이트웨이는 등록/로그인/키 설정 경로를 제공하지 않습니다. 세 역할을 한 AI로 통일하려면 독립성 감소 항목을 켭니다. 같은 AI를 사용해도 계획·구현·테스트·검수 단계를 구분하며, 회의 제안은 자동 채택하지 않고 대표 승인 대기로 둡니다. 새 등록 뒤 사용 가능 표시는 실제 추론 성공 전에는 검증 완료로 표시하지 않습니다. 명시적으로 고른 계정 대신 다른 AI로 자동 전환하지 않습니다.

- Codex / Claude: 공식 CLI 로그인 세션 또는 공식 API를 선택합니다. 앱의 로그인 버튼은 고정된 공식 명령을 별도 터미널로 열고, 사용자가 제공자 화면에서 직접 인증합니다. 로그인 성공을 CLI 설치 여부로 판단하지 않습니다.
- Google: **Antigravity CLI**와 **Gemini API**를 구분합니다. Gemini API만으로 세 역할을 운영할 수 있습니다. 현재 패치에 별도 `gemini` CLI 어댑터는 포함하지 않습니다.
- API: 서비스의 정확한 모델 ID를 입력하고 PC 환경변수 `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`에 키를 설정한 뒤 앱을 다시 실행합니다. 키 본문은 이 앱 설정 JSON이나 브라우저로 보내지 않습니다. API 비용은 CLI 구독과 별도입니다. 실제 API 토큰 응답을 아직 계량에 연결하지 않아 사용량 표시는 추정값입니다.
- 스킬: 직접 작성하거나 공개 GitHub의 `.md` 파일을 미리 가져와 검토한 후 활성화합니다. 부서별로 지정할 수 있고 기존 경로·예산·권한을 늘리지 않는 참고 지침으로 계획·구현·검수에 반영합니다. 의존성/셸 스크립트/MCP 서버/임의 플러그인 코드를 설치하지 않습니다.

[Hermes Agent 공식 저장소](https://github.com/NousResearch/hermes-agent)는 Nous Research의 별도 에이전트 실행 환경입니다. 스킬·플러그인·메모리·모델 연결을 제공하며 [공식 플러그인](https://github.com/NousResearch/hermes-official-plugins)도 있습니다. 이 패치에서 Hermes 런타임을 설치하거나 연결한 것은 아닙니다. 호환되는 Markdown 지침은 검토하여 가져올 수 있고, 도구 실행 플러그인은 별도 어댑터가 필요합니다.

사용자가 요청할 때까지 새 설치 ZIP과 다운로드 첨부를 만들지 않고 소스 패치를 누적합니다. 예전 ZIP에는 이번 변경이 포함되지 않습니다.

## 현대적인 사무실 배경

사무실 지도는 도시 전망의 통유리창, 밝은 타일 바닥, 화이트 데스크와 슬림 모니터, 라운지, 유리 회의실로 변경했습니다. 대기업 본사·자유로운 스튜디오·그린 오피스 모두 현대적인 인테리어를 사용하며 모던 우드/협업 보드/플랜트 월로 분위기를 구분합니다. 기존 저장 테마 ID와 방별/전체 적용 기능은 유지합니다.

픽셀 캐릭터와 직사각형 맵 이동은 유지하고, 캐릭터와 책상에 중복되던 이름표를 정리했습니다. 회의 참석자는 개인 책상을 회의 공간에 새로 만들지 않습니다. 화면용 SVG를 사용하므로 배경 표시를 위한 외부 이미지 생성/다운로드 호출이 없습니다.

회사 생성·테마 변경·부서 이동·대표 회의·모바일 화면을 기존 브라우저 시나리오 두 개로 검증했습니다. 새 설치 파일은 생성하지 않았습니다.

사무실과 동시 접속의 성능 변경·측정 방법은 [최적화 기록](PERFORMANCE_KO.md)을 참고하세요.
