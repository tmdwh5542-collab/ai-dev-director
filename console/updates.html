적용·복구 범위

코드·화면·리소스 업데이트는 사용자 설정과 작업 기록을 보존합니다. 파일을 직접 수정한 경우 적용을 보류합니다. 시작 검사 실패 시 적용 직전 코드·운영 기록으로 자동 복구합니다. 백업은 PC 내부 data/app_updates에 보관됩니다.

데스크톱 실행 파일·Python 의존성 변경이나 더 새로운 업데이트 도우미가 필요한 버전은 전체 설치를 안내합니다. 시작 검사는 백엔드 기동 확인이며 모든 UI·실사용 동작을 보증하지 않습니다.
