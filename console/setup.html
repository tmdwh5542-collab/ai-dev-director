순서대로 설치·연결하기

이 프로그램이 실행 중인 PC를 점검합니다. 다른 PC의 설치 상태는 확인하지 않습니다.

설치 상태를 확인하고 있습니다.

    1. Node.js·npm 확인

    필요 버전: Node.js 22.19 이상. Node.js는 공식 설치 파일로 설치하고, 설치 뒤 이 프로그램을 다시 실행해 PATH를 반영하세요. Windows에서 권한 확인 창이 나타날 수 있습니다.

    Node.js 공식 다운로드 ↗

    2. 웹 도구·Chromium 설치

      고정 버전 Playwright·Lighthouse·Monaco·PixiJS와 검수용 Chromium을 다운로드합니다. 선택한 프로젝트의 의존성, 운영 사이트와 AI 계정은 변경하지 않습니다. 네트워크와 저장 공간이 필요하며 실행 중인 AI 작업을 먼저 완료해야 합니다.

      설치 진행 기록
      

      3. MCP 연결 준비·검사
      프로젝트와 직원을 선택하면 허용된 조회·GitHub 참고 문서 보관 도구를 제공하는 연결을 검사합니다. 실제 AI 클라이언트 등록과 로그인은 별도 단계입니다.
      클라이언트의 MCP 설정에 병합하고 클라이언트에서 도구 목록이 나타나는지 확인하세요. 기존 설정을 통째로 덮어쓰지 마세요. 이 프로그램은 계정 설정 파일을 읽거나 덮어쓰지 않습니다. 클라이언트별 설정 위치·지원 형식은 설치된 공식 버전의 안내를 따르세요.
      직원별 도구 권한·공용 조사 담당 설정 →
      

      4. Hermes 선택 설정
      Hermes 없이도 일반 개발과 웹 검수를 사용할 수 있습니다. 사용하려면 Hermes 설치 Python·모델·키 환경변수 이름·요청 한도를 AI·스킬 설정에서 지정하세요. 실제 API 키는 PC 환경변수에 등록하고 이 화면이나 대화창에 붙여 넣지 마세요.
      AI 서비스 구독과 API 이용료는 별개일 수 있습니다. 설치 검사나 키 존재 여부로 인증·할당량·결제 상태를 판정하지 않으며, 이 점검은 유료 모델을 호출하지 않습니다.
      Hermes 설정으로 이동 →
      사무실로 이동
      Node·MCP·Hermes는 필요한 기능에 맞춰 나중에 설정할 수 있습니다. 이 버튼은 안내 확인만 기록하며 설치·계정 인증을 완료 처리하지 않습니다.
      앱 설치·도구 다운로드·MCP 브리지 검사·클라이언트 등록·AI 인증은 서로 다른 단계입니다.
