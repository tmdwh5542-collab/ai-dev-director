OneDrive · 운영 기록 백업 (PC 전용)

이 PC의 OneDrive 동기화 폴더를 선택하세요. OneDrive 로그인·동기화는 Windows OneDrive 앱에서 관리합니다. 게임 프로젝트 원본과 최종 작업트리는 별도 Git 또는 소스 백업으로 보관하세요. 운영 기록에도 대화와 업무 내용이 있으므로 개인 폴더를 사용하세요.

복구를 예약하면 다음 앱 시작 시 현재 운영 기록이 선택한 백업으로 교체됩니다. 먼저 현재 기록을 안전 백업합니다. 예약 후 새 작업을 시작하지 말고 시스템을 중지한 뒤 다시 실행하세요. 복구된 작업은 자동 재실행하지 않습니다. 다른 PC에서는 경로와 AI 설정을 다시 확인하세요.
