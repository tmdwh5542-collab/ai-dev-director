매일의 예약 업무

한국 시간 기준으로 완성된 영상을 검토하고 YouTube 공개 일정을 준비합니다.

반복 계획

영상과 공개 시간은 대표 검토 후 승인합니다. 활성화된 계획의 승인 영상만 최대 24시간 앞서 업로드합니다. 창만 닫아도 백엔드가 실행 중이면 예약 업무는 계속됩니다. PC가 꺼져 있으면 새 업무는 실행되지 않으며, 이미 YouTube에 예약된 공개는 YouTube가 처리합니다. 일시정지는 새 업로드를 막으며 이미 전송된 영상의 공개 예약을 해제하지 않습니다.

초안 생성만으로 업로드하지 않습니다. 일정 변경은 아직 업로드를 시작하지 않은 날짜부터 적용됩니다. 이미 업로드가 시작된 날짜는 기존 일정을 유지합니다.

YouTube 계정 연결 · PC 전용

Google Cloud에서 YouTube Data API를 켜고 ‘데스크톱 앱’ OAuth 클라이언트를 준비하세요. 계정 비밀번호는 앱에 입력하지 않습니다. 실제 Google 로그인은 이 PC의 기본 브라우저에서 진행합니다.

시크릿은 위 환경변수에 등록한 뒤 앱을 다시 실행하세요. API 할당량과 채널·프로젝트 상태에 따라 업로드·공개가 제한될 수 있습니다. 예약·공개 완료는 YouTube 응답을 조회해서 확인하며, 시간이 됐다는 이유만으로 완료 처리하지 않습니다.

준비된 영상 등록 · PC 전용

이번 기능은 완성된 영상의 예약 업로드입니다. 대본·음성·영상 자동 제작은 아직 연결하지 않았습니다. ffprobe로 길이와 해상도를 검사하며 파일당 최대 4GB입니다. 쇼츠 후보는 3분 이하 세로·정사각형이며 최종 분류는 YouTube가 결정합니다.

최근 7일 실적

공개 예정일 기준으로 집계합니다. 예약·공개 확인은 실제 YouTube 조회 결과입니다.

업무·공개 확인함

영상·제목·설명·아동용 및 합성 표시·공개 시각·대상 채널을 확인한 뒤 승인하세요. 실패·놓친 일정은 자동 재업로드하지 않습니다. 결과가 불명확하면 YouTube Studio에서 영상 ID를 확인해 연결하세요.
