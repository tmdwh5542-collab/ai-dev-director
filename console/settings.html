AI 연결 등록

CLI 연결: 이 PC에 설치한 공식 프로그램에서 계정 로그인합니다. 앱은 계정 비밀번호를 저장하지 않습니다. API 연결: 서비스별 별도 API 키와 이용 요금이 필요합니다.

API 키는 PC 환경변수(OPENAI_API_KEY / ANTHROPIC_API_KEY / GEMINI_API_KEY)에 등록한 뒤 앱을 다시 실행하세요. 여기에는 키 자체를 입력하지 않습니다. 연결 상태 표시는 설치·키 존재 여부이며 로그인·요금 한도는 실제 호출 전 미확인입니다.

Codex만 / Claude만 / Gemini API만으로 운영할 수 있습니다. 자동 테스트와 검수 단계는 유지됩니다. Antigravity CLI와 Gemini API는 서로 다른 연결 방식입니다.

Hermes Agent 실행 연동

Hermes가 설치된 별도 Python 환경을 사용합니다. 앱의 개발 AI 설정과 별도로 모델 API 연결을 등록하세요. Hermes 소프트웨어는 무료이며 모델 API에는 별도 요금이 발생할 수 있습니다. API 키 본문은 저장하지 않습니다.

초기 연동은 제공 자료·프로젝트 기록의 분석과 보고서 작성입니다. 개인 Hermes 설정·플러그인·MCP·장기 기억·셸·파일 변경을 사용하지 않으며, 기존 개발 실행·검수 단계는 유지합니다.

동시에 한 업무만 실행하며 자동 재시도하지 않습니다. 요청 건수 한도는 금액 한도와 다릅니다. 설치 점검은 실제 AI 인증·할당량을 확인하지 않습니다.

MCP 클라이언트 등록 정보
이 브리지는 선택한 직원·프로젝트에 고정됩니다. 읽기 도구만 제공하며 다른 MCP 서버나 AI 계정에 자동 등록하지 않습니다. MCP 클라이언트의 설정 형식에 맞춰 아래 값을 사용하세요.
프로젝트 작업 규칙 · 네 가지 원칙
정보 확인, 근거 있는 판단, 규모별 완료 검증, 이전 실패 참고를 공통 적용합니다. 작은 수정마다 질문·대표 승인을 요구하지 않습니다. 기존 AGENTS.md·CLAUDE.md 파일은 수정하지 않습니다.
    모든 수준에서 중요 기능은 실행 검증 대상입니다. 기존 테스트·회귀·범위·독립 검수를 생략하지 않습니다. 실제 실행 근거가 없으면 완료를 보류하고 필요한 설정을 안내합니다. 기존 Godot·Unity PlayMode의 감독관 실행 근거는 재사용합니다.
    등록한 명령은 다음 작업의 격리된 작업본에서 실행합니다. 운영 배포나 다운로드 명령을 넣지 마세요. 명령 성공은 적어둔 검증 범위의 근거이며 전체 수동 플레이 완료를 뜻하지 않습니다.
