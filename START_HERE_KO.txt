AI DEV DIRECTOR - 전용 데스크톱 앱 설치

1. ZIP 파일을 다운로드하고 '모두 압축 풀기'를 선택합니다.
2. AI DEV DIRECTOR 폴더의 INSTALL_DESKTOP.cmd를 더블클릭합니다.
3. 처음에는 패키지를 내려받고 전용 앱 EXE를 만듭니다. 완료될 때까지 기다려주세요.
4. 바탕화면에 'AI DEV DIRECTOR v3' 아이콘이 생기고 앱이 열립니다.
5. 이후에는 그 아이콘만 더블클릭하면 됩니다.

필요한 것
- Windows 10/11 64비트, Python 3.10 이상 64비트, Git, 첫 설치 시 인터넷
- Python: https://www.python.org/downloads/windows/
- Git: https://git-scm.com/download/win
- 실제 AI 개발에는 기존 안내처럼 로그인한 AI 코딩 CLI가 필요합니다.

전용 앱 창
- Qt 기반의 별도 프로그램 창에서 미션 센터를 엽니다.
- 바탕화면 바로가기는 설치 과정에서 만든 AI-DEV-DIRECTOR.exe를 실행합니다.
- 자체 아이콘, 창 제목, 앱 메뉴, 확대/축소, 보고서 파일 저장 기능을 제공합니다.
- 기존 웹 화면을 앱 내부 화면 엔진으로 표시합니다.
- 창을 닫아도 진행 중인 작업과 로컬 서버는 유지됩니다. 종료하려면 화면의 '시스템 중지'를 사용하세요.
- 기존 설정에 따라 중단된 미션이 시작 시 재개될 수 있습니다.

설치 위치
%LOCALAPPDATA%\AI Dev Director\mission-center-v3
다운로드/압축 해제 폴더를 옮겨도 설치된 앱과 바로가기는 유지됩니다.
기존 trial과 원래 바로가기는 보관합니다. 새 아이콘 이름은 AI DEV DIRECTOR v3입니다.
관리자 권한과 PowerShell 실행 정책 변경 없이 전용 Python 환경을 사용합니다.

문제가 생기면
- 재설치 전에 앱에서 '시스템 중지'를 누르고 전용 앱 창도 닫으세요.
- 재설치는 기존 config.yaml, companion.json, 데이터와 실행 기록을 보관합니다.
- 첫 설치 실패 시 설치 창의 오류 내용을 확인하고 다시 실행하세요.
- 실행 기록: 설치 폴더 data\desktop-launcher.log, desktop-server.log, desktop-server.err

이 ZIP에는 미리 빌드된 Windows EXE가 없습니다. 첫 설치 때 사용자 PC에서 EXE를 생성합니다.
Python 없이 설치되는 단일 실행 파일은 아닙니다.
Linux에서 전용 창의 실제 미션 UI 연결과 보고서 저장을 검증했습니다.
Windows EXE 생성 및 바탕화면 바로가기 실행은 Windows에서 추가 확인이 필요합니다.
